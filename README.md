# 办好了 · 公共服务办事引导助手

面向社保、居住证、公积金、异地就医等生活事务的中文响应式网站。提供办事路线、材料自查、对话式需求引导，以及处理退件、要求差异和跨城待办的「办事卡点」工作台。

在线版本：https://banhaole-guide-1028.sacredshore20.chatgpt.site

> 当前为可交互的本地数据版本，非官方政务平台，尚未连接大模型、审批接口或实时政策监测服务。豆包语音需服务端配置并单独开通对应服务。

## 快速运行

安装 Node.js 20 或更新版本后，在仓库根目录运行：

```bash
npm start
```

打开 http://127.0.0.1:4173 。无第三方依赖，不必先运行 npm install。环境变量 `PORT` 可修改端口；默认仅监听本机地址。

## 功能

- 城市与事项选择、演示办理路线、材料勾选、进度保存。
- 语音对话助手：规则识别城市、事项、办理情形；支持文字输入、浏览器语音识别与回复朗读，并可进入卡点工具。
- 材料清单下载、日历提醒文件下载；导入设备日历后由日历执行提醒。
- 退件修复：拆解通知，生成补正检查与询问清单。
- 要求差异核对：比较两份文本，保留不同条目、日期和来源。
- 跨城排程：按用户填写的耗时与前置关系计算并行和等待顺序。
- 版本检查：手动粘贴指南基准与新版本，关联计划并提示待核对变化。
- 卡点记录保存、状态更新、行动单下载、刷新恢复。
- 电脑和手机响应式界面；折纸几何 b 品牌 Logo。

## 数据与能力边界

计划和记录保存在当前来源的浏览器 localStorage。清除浏览器数据、换设备或更换域名不会自动同步。

请先对材料自行脱敏，不要粘贴真实证件等敏感信息。程序会尝试隐藏常见身份证号和手机号，但无法保证识别所有个人信息。

材料、办理资格、费用、时限、地址、渠道及代办条件须向当地官方核验。网站不会提交政务申请，不判断行政要求的法律效力，不承诺审批结果。

豆包声音可通过服务端接入；没有配置时继续使用浏览器语音。语音输入和朗读会由相应语音服务处理，麦克风需要授权。退件解析和对话是规则式整理。逐条文本差异不等于政策实质变化。排程使用用户估计的自然日，未考虑节假日、预约号源及待遇接续判断。版本检查不会自动访问官网，也不会在网页关闭后推送通知。

## 文件

- `dist/index.html`：页面结构。
- `dist/style.css`、`dist/refined.css`：基础与品牌响应式样式。
- `dist/logo.svg`：品牌标志。
- `dist/app.js`：路线、清单、进度和日历提醒。
- `dist/chat.js`：规则式对话向导。
- `dist/voice.js`、`dist/voice.css`：语音输入、回复朗读和语音助手界面。
- `dist/doubao-voice.js`：豆包语音录制、识别及合成播放。
- `services/voice-router.mjs`：豆包识别和合成的服务端代理；密钥不发送给浏览器。
- `dist/refined.js`：图标和品牌界面处理。
- `dist/case-engine.js`：退件、文本差异与依赖排程核心算法。
- `dist/cases.js`、`dist/cases.css`：卡点工作台。
- `server.cjs`：无依赖本地静态服务器。
- `check-chat.cjs`、`check-cases.cjs`：逻辑检查。

## 可选：豆包语音配置

在服务端环境中设置 `VOLCENGINE_API_KEY`，并在同一火山项目中开通语音合成模型 2.0 和录音文件识别极速版。语音合成使用 `seed-tts-2.0`，可用 `VOLCENGINE_TTS_SPEAKER` 设置已授权音色；默认使用 `zh_female_vv_uranus_bigtts`。在识别权限确认开通之后，可将 `VOLCENGINE_ASR_ENABLED` 设为 `true`，启用豆包语音输入；未启用时使用浏览器语音识别。

密钥只应放在服务器环境或托管平台的密钥管理中，不能提交到 Git、写进网页或公开。项目默认仅监听本机，开发服务器的本地身份标记不能作为公开生产环境的身份验证。火山服务可能计费，实际开通权限和费用以控制台为准。语音服务只处理识别与朗读，并不提供大模型对话。

## 验证

```bash
npm test
```

覆盖需求识别、分步追问、路线保存、导出换行、脱敏、退件分类、差异去重、并行排程、依赖异常、来源链接协议限制。检查不替代真实政策核验。

## 部署

无需构建，将 `dist/` 作为静态站点目录部署即可。本仓库没有自动启用 GitHub Pages，现有在线网站与仓库也不会自动同步，修改后需另行部署。
